**EKRS:**


EKRS (Enterprise Knowledge & Reasoning System) is a multi-cloud platform for secure enterprise document ingestion, semantic retrieval, and decentralized long-form reasoning. The system combines AWS serverless OCR pipelines, GCP-based embedding and vector search services, and Azure peer-to-peer reasoning nodes into a unified event-driven architecture. Documents are transformed into semantic embeddings for contextual querying, while distributed Azure peers collaboratively execute long-form analytical tasks using the GCP retrieval layer. The project demonstrates how managed PaaS services across multiple cloud providers can be orchestrated to build scalable and privacy-aware enterprise AI systems.
